- Каталог: отмена загрузки, общий deadline 30 s, отдельный сетевой пул, понятные ошибки и отбрасывание результатов отменённых запросов.
- Добавлена Android-страница заявок публичных GitHub-репозиториев и серверная очередь. Администратор проверяет конкретный стабильный Release и точный SHA-256 перед публикацией; version manifest совпадает с тегом Release. Каждая новая версия модерируется отдельно.
- Theme overrides обновляют зарегистрированные открытые страницы и кеши RecyclerView; сохраняются черновики и навигация.
- Изменены системные границы: ApplicationLoader/PluginRecovery для отдельного probe-процесса, Full PluginHost для обновления существующих страниц, подписанный API для заявок. Проверки и итоговый артефакт будут записаны после приёмки.
