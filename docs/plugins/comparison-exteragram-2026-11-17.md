# Плагины BYgram и exteraGram

Этот срез сделан до добавления файловых хуков, `register_cleanup` и расширения AccountClient и Java Proxy. Текущий API описан в [руководстве по переносу](exteragram-port.md) и [англоязычной документации](https://byxarek.site/TEST-PROJECT/BYgram/docs/en/).

Срез от 17 ноября 2026 года. Сторона BYgram проверена по Python API, Android-хосту и инструментам в рабочей копии. Для exteraGram сверены декларации `.pyi` из официального стабильного SDK 1.4.6.4, Python-обёртка Elyx из пакета arm64 и опубликованный справочник. SHA-256 обоих архивов совпали с данными релиза. Большинство модулей exteraGram поставляется в виде `.so`, поэтому сравнение их внутренних механизмов ограничено опубликованным контрактом. [Релиз SDK](https://github.com/exteraSquad/plugins-pysdk-builds/releases/tag/sdk-v1.4.6.4-stable-41641758760-1) · [Архив клиента](https://github.com/exteraSquad/exteraGram)

Для типового плагина с Telegram-хуками, меню и настройками есть путь импорта в BYgram. Совместимость зависит от конкретных вызовов, особенно для файловых хуков, регистрации очистки, Java-прокси и методов `AccountClient`. Старые сравнительные отчёты фиксируют состояние до реализации многострочных настроек, before-Intent и поддержки `.pyc`. Текущие правила импорта собраны в [руководстве по переносу](exteragram-port.md).

## Сайты документации

Оба опубликованных сайта ответили HTTP 200. Проверены HTML, адреса разделов, доступность поиска и структура справочника. Поведение BYgram дополнительно сверено с кодом сайта.

| Критерий | BYgram | exteraGram |
| --- | --- | --- |
| Структура и навигация | Русская документация на одной странице. Разделы открываются по `#якорю`. Есть боковое меню, оглавление текущего раздела, переходы между разделами и переключатель темы. | Английский справочник с отдельными маршрутами для разделов. Есть боковое меню, оглавление страницы и переходы к соседним статьям. Вложенные статьи Elyx имеют собственные адреса. [Сайт BYgram](https://byxarek.site/TEST-PROJECT/BYgram/docs/) · [Сайт exteraGram](https://plugins.exteragram.app/docs) |
| Поиск и ссылка на ответ | Ctrl/Cmd+K ищет в тексте всех разделов на клиенте. Результат ведёт к началу подходящего раздела. Оглавление внутри раздела позволяет скопировать ссылку на отдельный заголовок. | Публичный глобальный поиск и отдельные адреса статей и заголовков. Узкие разделы, например о прокси и Intent, проще цитировать по самостоятельному URL. [Код страницы BYgram](../../server/site/docs/docs.js) · [Пример статьи exteraGram](https://plugins.exteragram.app/docs/intents) |
| Примеры и полнота API | Первый пример и манифест подтягиваются из файлов проекта, JSON Schema можно скачать. Есть отдельные инструкции для `.byplugin`, допуска, проверок и публикации. Части совместимого API разнесены по веб-справочнику и руководству по переносу. | Больше самостоятельных страниц по API и сценариям Elyx.
