# Плагины BYgram для Android

Обновлено 01.11.2026. **Последнее обновление backend и аудит оставшихся работ:** [hook и аудит](hook-update-and-audit-2026-11-01.md). Предыдущий этап: [надёжность, модерация и приёмка](reliability-and-moderation-2026-11-01.md). Отчёты других проходов ниже — история конкретных снимков, не статус нынешнего кода. Full: Android 7.0+ (API 24); Lite: API 23, без Python/AliuHook и каталога.

В Full: **Настройки → Настройки BYgram → Плагины**. Доступны установка из файла и каталога, отдельное включение движка/плагина, настройки и выбор аккаунтов, журнал, импорт/экспорт настроек, pending update/отмена, rollback и safe mode. Каталог начинается с шести SDK-примеров; загрузка проверяет manifest/размер/SHA-256 и не включает код автоматически.

**Python в процессе BYgram — доверенный код, а не sandbox.** Установка и разрешение исполнения — разные действия; metadata автора и SHA-256 не являются подписью издателя. Возможности SDK не позволяют менять правила сервера Telegram или гарантировать совместимость с любым внутренним Java-методом.

Native backend закреплён как `1.1.4-api37.1-bygram.3`, fork `43b0d8d`. Кандидаты: 64-bit primary x86_64/arm64 API 24–37. До native init основного клиента встроенный Python/native hook/unhook/GC probe проверяет конкретное устройство в отдельном процессе; crash/timeout закрывает backend до restart. Это проверка при запуске, не обещание аппаратного покрытия всех OS/OEM. Core SDK доступен без raw hooks. Последний владелец закрывает native dispatcher после завершения активных вызовов; прежняя retention-заглушка удалена.

«Добавить плагин в каталог» открывает native-страницу заявки. Нужен публичный GitHub-репозиторий со стабильным Release и одним `.byplugin`. Тег `v1.2.3`/`1.2.3` определяет версию и должен совпасть с manifest. Администратор проверяет точный кандидат; новый Release требует отдельной модерации. Для администратора: `/api/plugins.php`, действующая Telegram admin session и CSRF. Модерация не является sandbox или криптографической подписью автора.

Системные интерфейсы и исправления обычных страниц Telegram фиксируются в документации с датой; Android-изменения — в корневом changelog.md. Сборка: один итоговый APK после проверок, доставка в Избранное Telegram.
