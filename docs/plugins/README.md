# Плагины BYgram для Android

[Публичная документация и каталог плагинов](https://byxarek.site/TEST-PROJECT/BYgram/docs/) включают руководство по установке, первый плагин и справочник SDK. Исходники сайта находятся в `server/site/docs/`. Сборка выполняется командой `npm run build` из `server/site/`, а список пакетов загружается из действующего каталога BYgram.

[Англоязычная документация](https://byxarek.site/TEST-PROJECT/BYgram/docs/en/) содержит отдельные статьи по Elyx, жизненному циклу, аккаунтам, файловым хукам, прокси и вспомогательным API.

Доступны на Android 7.0+: **Настройки → Настройки BYgram → Плагины · БЕТА**. Установить `.byplugin` можно из файла или каталога. Движок и плагин включаются отдельно. В менеджере доступны выбор аккаунтов, настройки, журнал, обновление, откат и безопасный режим.

«Настройки BYgram → Плагины · БЕТА» показывает установленные плагины карточками. Закреплённые идут первыми, закрепление сохраняется при обновлении и откате. Карточка позволяет включить плагин после подтверждения, поделиться `.byplugin`, открыть список файлов Python и `manifest.json` для чтения, перейти к настройкам и удалить плагин с выбором судьбы его данных. Настройки, которые формирует код плагина, доступны после его включения. Для строк с `link_alias` долгое нажатие открывает меню копирования и отправки ссылки. Ссылка открывает страницу и подсвечивает строку.

Просмотр файла из чата, системного выбора и каталога использует ту же проверку пакета. В нижнем окне видны описание, версия, источник, проверенная подпись при наличии, SHA-256 и заявленные возможности. Для локального файла требуется подтверждение. Установка сохраняет плагин выключенным до отдельного разрешения на исполнение. Android может передать файл из другого приложения по MIME-типу `application/vnd.bygram.plugin` или по доступному имени `.byplugin` в URI. Если файловый менеджер скрывает имя и передаёт общий MIME-тип, используйте «Установить из файла» в разделе плагинов.

Новые установки сохраняют оригинальный архив для отправки. Для старых установок экспорт собирает ZIP из файлов пакета. У такого ZIP может отличаться SHA-256 архива, а подпись автора проверяется по содержимому. Настройки и пользовательские данные хранятся отдельно от пакета. Просмотр длинных исходников показывает первые 128 КиБ файла с пометкой.

С 12.11.2026 BYgram автоматически включает безопасный режим в фоновой очереди при запуске после прерванной активации или при ошибке восстановления. Приложение открывается без плагинов и показывает уведомление, если Android разрешает уведомления BYgram. Нажатие открывает экран в отдельном процессе `:plugin_recovery`. Выход из безопасного режима оставляет движок и плагины выключенными.

**Устанавливайте только доверенный код.** Python-плагин работает с правами процесса BYgram. Имя автора и SHA-256 сами по себе не подтверждают личность издателя. Проверка каталога не изолирует код.

## Каталог и разработка

[Скиллы для ИИ](agent-skills.md) подключают рабочий процесс BYgram к Codex, Claude Code, Gemini CLI, Cursor и Copilot. Для DeepSeek и других чатов доступен готовый промпт.

[Технический план платного каталога](paid-catalog-plan.md) описывает публикацию, оплату Stars и TON и выдачу пакетов покупателям.
[Реализация и тестирование платного каталога](paid-catalog.md) описывает новые экраны, настройки торгового бота и локальную проверку без списаний.
[Руководство покупателя](https://byxarek.site/TEST-PROJECT/BYgram/docs/purchases.html) объясняет оплату, восстановление доступа и помощь с заказом.

«Каталог плагинов» показывает список, поиск по названию и ID, фильтр по категориям и кнопку подачи заявки. Иконки-стикеры берутся из метаданных каталога. Для остальных записей используется стандартная иконка. Строка «Источник каталога» позволяет переключить источник или добавить HTTPS-индекс BYgram, `extera-plugins.json`, GitHub-репозиторий или публичный Telegram-канал. Индекс BYgram принимает `{"format":1,"plugins":[...]}`. Каждая запись содержит `manifest`, `sha256`, `size` и имя `file` вида `<sha256>.byplugin`. Разместите архивы рядом с индексом. Для HTTPS-файлов exteraGram клиент сверяет размер, SHA-256, ID и версию и преобразует исходники на устройстве. В Telegram-канале каталог просматривает до 2000 документов, с ограничением на фоновую загрузку метаданных. Сторонние пакеты устанавливаются с подтверждением неизвестного источника.

«Посмотреть код» для импортированного `.plugin` exteraGram открывает его Python-текст из `main.py`. Кнопка «Файлы» открывает список исходников и метаданных пакета. Просмотр кода доступен до установки и после неё.

Переключатель «Выполнять плагины» следует настройке переключателей Material 3. При удалении одно окно предлагает сохранить или удалить настройки плагина, затем показывает индикатор до завершения фоновой операции.

«Добавить плагин в каталог» открывает native-страницу заявки. Нужен публичный GitHub-репозиторий со стабильным Release и одним `.byplugin`. Тег `v1.2.3`/`1.2.3` определяет версию и должен совпасть с manifest. Администратор проверяет точный кандидат; новый Release требует отдельной модерации. Для администратора: `/api/plugins.php`, действующая Telegram admin session и CSRF. Администратор может отозвать опубликованный релиз по SHA-256. Каталог прекращает выдавать этот пакет, а BYgram отключает установленную копию после получения списка отзывов. Модерация не является sandbox или криптографической подписью автора.

Native backend закреплён как `1.1.4-api37.1-bygram.3`, fork `43b0d8d`. Кандидаты на API 24+ — все четыре ABI APK: arm64-v8a, armeabi-v7a, x86_64 и x86. Допуск конкретного устройства зависит от пробы. До native init основного клиента встроенный Python/native hook/unhook/GC probe проверяет конкретное устройство в отдельном процессе; crash/timeout закрывает backend до restart. Это проверка при запуске, не обещание аппаратного покрытия всех OS/OEM. Core SDK доступен без raw hooks. Последний владелец закрывает native dispatcher после завершения активных вызовов; прежняя retention-заглушка удалена.
