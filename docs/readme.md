## Android-клиент

14.10.2026: в выборе иконки оставлены BYgram (по умолчанию, `bygram-logo.png`) и Telegram; MD3-переключатели используют официальный `MaterialSwitch` с цветами темы Telegram. Статусы печати перенесены в «Кастомизацию», оформлены общие поля PIN/пароля/статуса, исправлены геометрия MD3-переключателей, стандартный стиль слайдера и согласование формы аватаров с реакциями и заголовком чата. Подробности — в [документе кастомизации](bygram-settings/customization.md).

Основа Android-исходников обновлена до официального Telegram commit `f32ffeec763f0bdbf4bec25b52d654f77bff733d` (13.0.2, базовый versionCode 7175). Полностью перенесён диапазон `dc780e81..f32ffee`, включая промежуточные коммиты и ревизии submodules. Сохранён package `com.bygram.mobile`. Совместимость BYgram и ограничения проверки описаны в [отчёте обновления](bygram-settings/telegram-13.0.2-upgrade.md).

История предыдущего обновления: основа соответствовала `dc780e81ed1261c369c27870e8e0999a1eb0b600`. После `9552e5541e1274b9557c9832b204dbfcaf44b3dc` последовательно перенесены `2ad0f47d` (submodules), `c8480176` (исходники Telegram 12.10.4) и `dc780e81` (исходники Telegram 12.10.5). На той базе версия Android-клиента была `12.10.5`, базовый versionCode `7105`.

В `SettingsActivity` ID `24` сохранён за пунктом Telegram для настроек круглых видео. Разделу BYgram назначен постоянный `BYGRAM_SETTINGS_ID = 1000`.
Для flavor `afat` Gradle формирует итоговый versionCode `71759` из базового `7175` и ABI-кода `9`; это сохраняет возможность обновления поверх прежних APK с кодами `71059` и `70899`.

Переключатели Material 3 рисуются в пределах выделенного им места; детали и проверка — в [документе по кастомизации](bygram-settings/customization.md).
Штатный переключатель «Жидкое стекло» находится в настройках анимаций чата; отдельная маска эффектов BYgram удалена. Скрытые и запароленные чаты описаны в [документе о приватности](bygram-settings/privacy-modes.md): их уведомления не показывают сообщение, а PIN открывает вкладку скрытых чатов прямо в поиске. Устаревшая интеграция значка ExteraGram удалена из серверного кода и схемы новых установок.
Список чатов перестраивает имя после получения BYgram-значка из API; в заголовке «Избранного» значок пользователя не показывается. На страницах скрытых и запароленных чатов выбранные диалоги показаны строками с аватаром и последним сообщением, добавление перенесено в «+» заголовка. Профиль пересчитывает высоту области аватара, когда музыкальная карточка появляется при открытии или после загрузки данных пользователя. Регрессионная проверка: `python Tools/check_bygram_settings_fixes.py`.

Просмотры профиля доступны в Lite и Full: пункт находится на главной странице настроек BYgram, следы в своём профиле открывают список и переключатель. Посещение записывается, только если функция включена у обоих пользователей; список хранится 7 дней. Для подтверждения Lite используется существующая привязка через Telegram-бота для статусов печати, Full также может использовать ключ лицензированного устройства. Серверные таблицы: `profile_view_settings`, `profile_views`; миграция `server/activity-api/migrations/20260928_profile_views.php`. Аватары вне локального кэша загружаются через `server/activity-api/avatar.php` по подписанному часовому URL; PHP перед каждой отдачей проверяет согласие обоих участников и срок записи. В списке открывается Telegram-профиль доступного пользователя или публичный username; если пользователь неизвестен клиенту и не имеет username, открывается карточка с аватаром, именем и ID. Уведомления опрашиваются раз в минуту при открытом приложении и фоновым Android JobScheduler (не чаще одного раза в 15 минут); доставка может задерживаться из-за ограничений Android и сети. На страницах скрытых и запароленных чатов красная корзина удаляет чат из соответствующего списка, нажатие на строку открывает чат.

В списке просмотров Android и Windows рядом с именем показывается локальное время последнего посещения; публичный username в строке скрыт, но Android по-прежнему использует его для открытия неизвестного клиента пользователя. Новые посетители подсвечены при первом открытии списка. Состояние просмотра хранится на сервере в `profile_views.seen_at`, синхронизируется между клиентами и сбрасывается при повторном посещении; для существующей базы нужна миграция `server/activity-api/migrations/20260930_profile_views_seen.php`. В своём профиле Android и Windows показывают аватар последнего нового посетителя и число новых под ним; при отсутствии новых посетителей возвращается обычная иконка. Для этого API добавлены `profile_views_summary` и `profile_views_seen`; отметка уведомления `notified_at` остаётся независимой.

Открытие `profile_views_list` отмечает всех показанных посетителей прочитанными на сервере. Список в ответе сохраняет `is_new` на момент открытия, а повторный запрос `profile_views_summary` после возврата в профиль сбрасывает аватар и счётчик. Это правило общее для Android и Windows; новые посещения после открытия списка снова считаются новыми.

## Desktop-клиент

Исходники обеих версий публикуются в закрытом репозитории [BYgram-mobile](https://github.com/BYxarek/BYgram-mobile): Android и сервер — ветка `main`, ПК-клиент — ветка [desktop](https://github.com/BYxarek/BYgram-mobile/tree/desktop). Для получения ПК-исходников используйте `git clone --branch desktop --recurse-submodules https://github.com/BYxarek/BYgram-mobile.git BYgram-desktop/tdesktop`. Сборочные зависимости, бинарники и локальные журналы в Git не включаются.

Исходники [Telegram Desktop](https://github.com/telegramdesktop/tdesktop) с рекурсивными подмодулями размещены в соседнем каталоге `../BYgram-desktop/tdesktop` (ветка `dev`, commit `e15f444cdb2ae6ffdb60ff19d297fcfabd39f72d`). Сборочные зависимости для Windows x64 подготовлены штатным `Telegram/build/prepare/win.bat` в `../BYgram-desktop/ThirdParty` и `../BYgram-desktop/Libraries/win64`. Локально скрипт адаптирован к доступному пакету MSYS2 `diffutils` и зеркалу Qt для `jom`; необязательная утилита `dump_syms` не собрана без компонента ATL/MFC Visual Studio.

Для подготовки используется Python 3.10, MSVC 14.44 из Visual Studio 2022 и CMake/Ninja из Visual Studio Build Tools 2026. В desktop CMake по умолчанию используются `api_id` и `api_hash` из мобильного BYgram; их по-прежнему можно переопределить через `TDESKTOP_API_ID` и `TDESKTOP_API_HASH`. Команды сборки приведены в [официальной инструкции Windows](https://github.com/telegramdesktop/tdesktop/blob/dev/docs/building-win.md). В desktop добавлена вкладка BYgram Settings: Ghost Mode с отдельными блокировками прочтения, просмотра историй, online и typing; отправка сообщения или реакции может временно разрешить read receipt при включённом «Read on actions». Добавлены режим отображения ID профиля, экспорт действующих настроек в JSON, сброс этих настроек и ссылки на канал, чат и репозиторий переводов. Добавлены фильтр Zalgo для сообщений, настройка скругления аватаров, сохранение последнего замеченного online, локальные диапазоны дат прочтения и текстовая история правок. Для `noforwards` открыты пути локального сохранения и копирования медиа с сохранением ограничений TTL и нераскрытых платных медиа. Добавлены код сохранения удалённых сообщений под Windows DPAPI, скрытые чаты/PIN и пароли чатов, музыкальная карточка с обложкой, статусы печати Full, оригинальные значки BYgram, лицензирование CNG/ACL/активность и просмотры профиля. Подробности и матрица ещё не выполненных проверок: [девять Windows-функций](bygram-settings/desktop-nine-features.md). Актуальная Windows Debug-сборка успешно скомпилирована и слинкована 30.09.2026; проверка с реальными аккаунтами не проведена. Пересылка новой копией защищённых медиа и остальные частичные пункты остаются в общем отчёте. Точные статусы и непройденные тесты перечислены в отчёте. Версию клиента не изменяли.

Следующая правка Windows UI убирает кастомизацию Material 3, перемещает раздел BYgram наверх настроек и выделяет его, переводит собственные настройки на русский при русском языке клиента, добавляет иконки пунктам, заменяет окно значка команды на toast и выводит скругление аватаров ползунком с предпросмотром. `logo-new.png` используется для встроенного логотипа и Windows-иконки; название окна и сведения EXE показывают BYgram.


В Windows дополнительные параметры режима призрака показываются только при включённом основном переключателе. Переключатели не имеют иконок в подписи. Диалоги BYgram для подтверждений, PIN, паролей, выбора действий и списка просмотров используют встроенные слои Telegram; экспорт настроек вызывает штатный файловый диалог клиента. Ссылки `t.me`, включая подтверждение BYgram Full в боте, открываются внутри клиента; внешние сайты по-прежнему открываются браузером.

Исправление от 30.09.2026: скрытые параметры призрака теперь схлопываются вместе с высотой блока. Вызов окон из кнопок настроек и меню чата откладывается до завершения обработки нажатия, а ожидание завершается по событию закрытия слоя Telegram. Пустой список скрытых чатов показывает сообщение без запроса PIN. При HTTP 401 на интерактивных запросах просмотров профиля Windows-клиент обновляет подтверждение устройства и повторяет запрос; если ключ всё ещё не зарегистрирован, открывает регистрацию через бота. Ответ регистрации бота не считается подтверждением включения просмотров: ожидающая настройка сохраняется до ответа сервера с полем `enabled`. Новые тексты опубликованы в `BYgram-translations` коммитом `ac216f7`. После этой правки 30.09.2026 успешно собраны Android Full Debug (`output/BYgram-full-debug.apk`, package `com.bygram.mobile`, versionName `12.10.5`, versionCode `71059`) и Windows x64 Debug (`../BYgram-desktop/output/BYgram-debug.exe`). Подпись APK и бинарная локализация проверены; после запуска Windows проведена частичная проверка на двух аккаунтах и собран исправленный `../BYgram-desktop/output/BYgram-debug-fixed.exe`. Покрытие и ограничения — в [отчёте аудита](bygram-settings/desktop-debug-audit-2026-09-30.md). Версии клиентов не изменяли.

Новые английские и русские тексты Windows опубликованы в `BYgram-translations` коммитами `57f9125`, `c03960e` и `ebf812f` (`locales/*/bygram_desktop.json`). Текущая desktop-сборка использует эти пары фраз непосредственно в C++; репозиторий переводов служит открытым каталогом для правок.

## Сайт и релиз Lite от 25.09.2026

Публичные страницы `server/site`: главная, `features.html` с реальными скриншотами из эмулятора, `editions.html` со сравнением Lite/Full и `download.html`. Ссылка покупки ведёт через `server/activity-api/manager.php`, который при каждом переходе читает `app_settings.manager_username` и перенаправляет в Telegram. Не закрепляйте username менеджера в HTML.

На странице функций отдельно помечены снимки скрытых и запароленных чатов из тестовой Full Debug 12.10.5. Страница скачивания продолжает показывать опубликованный Lite APK 12.10.3 до отдельного релиза; debug APK на сервер не выкладывается.

Release Lite собран командой из [инструкции](build.md) без изменения `APP_VERSION_*`: APK `output/BYgram-lite-12.10.3.apk`, package `com.bygram.mobile`, versionName `12.10.3`, итоговый variant versionCode `70899`, размер `115657162` байт, SHA-256 `4EC5391C7FC5EBDDB74118DEAC8EB45A506465F7E9B1DA8E725F851A3B09118A`. Публичные данные релиза находятся в `server/activity-api/release.json`; APK публикуется рядом со страницей сайта. Скриншоты должны соответствовать версии сайта; страницы не описывают функцию BYxarek badge.

## Правила сопровождения

- Основной Android package: `com.bygram.mobile`; не добавляйте `.debug`, `.test` или `.beta` к `applicationId` приложения.
- `com.bygram.mobile.test` — отдельный тестовый package instrumentation APK.
- Не меняйте версию клиента без прямого запроса.
- Переводы BYgram ведутся в публичном репозитории [BYgram-translations](https://github.com/BYxarek/BYgram-translations). После проверки pull request импортируйте их в закрытый проект командой из [инструкции по сборке](build.md); сборка использует зафиксированные XML-файлы и не зависит от Crowdin.
- Не уменьшайте версии KotlinPoet `2.3.0`, credentials `1.6.0`, dynamicanimation `1.1`.
- После изменения функций обновите соответствующий документ и минимальную runnable-проверку.
- При публикации релиза обновите metadata и страницу скачивания APK.
