# Перенос настроек BYgram в Windows-клиент

Состояние на 30.09.2026. Полный перенос ещё не завершён. Источник функций: Android `BygramSettingsActivity`, `BygramConfig` и документы этого каталога. Целевой код: `../BYgram-desktop/tdesktop/Telegram/SourceFiles`. Статус «реализовано» означает наличие UI, сохранения настройки и потребителя в коде; итоговая проверка Windows Debug-сборки отмечается отдельно.

Проверки: XML каталога переводов и `git diff --check` прошли. Отдельная Windows Debug-проверка `tools/bygram/text_test.cpp` собрана и выполнена: фильтр Zalgo, диапазоны дат прочтения, история правок и 90-дневный срок хранения. Полный Windows Debug-проход и три последующие инкрементальные сборки собраны и слинкованы, последняя — после очистки устаревших Spy-данных при старте. Актуальная Windows Debug-сборка всех девяти блоков успешно скомпилирована и слинкована 30.09.2026, включая исправления жизненного цикла активности и масштабирования музыки. Частичная проверка Windows UI на двух аккаунтах выполнена; результаты, исправления и ограничения — в [отчёте аудита](desktop-debug-audit-2026-09-30.md). Дополнительно успешно выполнены PIN/пароль, ACL, canonical POST, DPAPI и CNG-проверки. Самостоятельную сборку Android APK выполняет владелец проекта после изменений.

После сборки нужны ручные проверки в Windows: переключение Ghost в личном/групповом чате и истории; фильтр Zalgo до и после повторного открытия диалога; скругление аватаров в списке, профиле и форуме; сохранение online, перезапуск клиента, истечение срока и очистка истории. Проверка запрета прочтений в личном чате и крайних положений ползунка выполнена; остальные перечисленные сценарии ещё не выполнены.
