## Хранение и границы

- Verifier PIN/паролей и API preferences разделены по Telegram-аккаунту и окружению. Закрытый ключ находится в Windows CNG; приватная часть не экспортируется.
- Spy хранит MTP-снимки в `tdata/bygram-deleted/<session>/<peer>/`. DPAPI связывает файлы с текущим Windows-пользователем. Архивируются сообщения, которые клиент ранее получил при включённом Spy; удалённый до первого получения контент восстановить нельзя.
- Снимок хранит Telegram-ссылки на медиа, а не гарантирует сохранность ещё не скачанного файла после удаления на сервере. Ранее скачанные файлы обслуживает штатный cache/download layer.
- Production BYgram API отключён для Telegram test accounts: тестовый Telegram ID не должен использоваться как production identity.
- Экспорт настроек содержит только разрешённые переключатели и параметры, без access/refresh токенов, verifier паролей и архива сообщений.
- Изменения Material 3 внутри Git submodule `Telegram/lib_ui` удалены; остальные функции используют штатный UI.
- Новые фразы опубликованы в `BYgram-translations`: `8c4d61a`, `d4026c9`, `6226194`, `3fdb87d`. Пользовательские окна Windows пока содержат английские подписи; каталог переводов опубликован отдельно.

Активность выбирается по текущему окну и аккаунту, прекращается при неактивности/блокировке и возобновляется при возвращении. Позднее подтверждение прежнего запроса обрабатывается очисткой; ACL и лицензия обновляются независимо от открытого раздела. Посещения профиля учитываются только для активного окна и не требуют включения Full-публикации активности. Проверки смены аккаунта/окна, сворачивания, позднего ответа сервера и посещений при отключённой активности **НЕ ПРОВЕДЕНЫ**.
