# Профиль, прокрутка и временно бесплатный Full — 24.10.2026

## Кастомизация Android и iOS

Все три переключателя по умолчанию выключены, входят в экспорт и сброс:

| Настройка | Ключ | Публичная ссылка |
| --- | --- | --- |
| Растянуть фон на весь профиль | `bygram_full_profile_background` | `profile.7` |
| Сворачивать папки при прокрутке вниз | `bygram_collapse_folders_on_scroll` | `general.12` |
| Сворачивать нижнюю навигацию при прокрутке вниз | `bygram_collapse_navigation_on_scroll` | `general.13` |

Фон занимает окно профиля, включая информацию и область публикаций/медиа.
Android повторно использует один ImageReceiver и единые координаты окна для фона
списка, непрозрачных строк и шапки; шапка ограничивает рисование своей высотой.
ImageReceiver инвалидирует весь TopView и список, чтобы кадры GIF обновлялись
также под нижними блоками. Смена цвета фона списка сохраняет отрисовку изображения.
iOS переносит существующий BygramProfileBackgroundView под содержимое страницы,
делает фон информационных секций полупрозрачным и снимает фон контейнера панелей.
Вторая копия GIF не декодируется. Если файл отсутствует или ещё загружается,
сохраняется обычное оформление. Отключение чужих фонов продолжает действовать.

Папки и нижняя панель сворачиваются при ручной прокрутке главного списка чатов
вниз и возвращаются при прокрутке вверх или возвращении на экран. Папки и
навигация управляются независимо. Поиск, архив и выбор получателей не запускают
это поведение. iOS использует направление жеста, в том числе когда абсолютное
смещение длинного списка неизвестно; папки убираются штатным компонентом панелей.
Анимация сворачивания папок — 250 мс; Android сохраняет штатную анимацию панели.

## Заголовки Android

Стекло профиля использует iBlur3FactoryLiquidGlass и фон самого профиля,
включая изображение шапки. Это охватывает QR-кнопку и блок действий с посетителями
и меню. Сохраняются системные ограничения размытия и Liquid Glass.

Обычные заголовки ActionBar располагаются по центру экрана с ограничением по
соседним кнопкам. Изменение прозрачности контейнера заголовков явно инвалидирует
ActionBar: рамка настроек перерисовывается и исчезает вместе с текстом при
возвращении наверх. Собственные заголовки чата/списка сохраняют свои настройки.

## Временное отключение платной лицензии

Серверный `license_checks_enabled` по умолчанию `false`.
Для обратного включения добавьте в production `config.php`:

```php
'license_checks_enabled' => true,
```

Код платной проверки и лицензии в БД сохранены. Переключатель действует на оба
клиента через общий API, включая активацию, восстановление сессии, activity и
публикацию через зарегистрированный Full-ключ. Подтверждение Telegram ID ботом,
подпись, timestamp/nonce, токены, отзыв устройства и лимит двух устройств
сохранены. Первому устройству всё ещё нужно подтвердить аккаунт — это не оплата.
Позднее в этот день эти проверки получили отдельные флаги и были отключены:
[актуальная политика](access-policy-flags-2026-10-24.md).

На production обновлены только `bootstrap.php` и `index.php`. В bootstrap
сохранены найденные только на сервере функции оплаты, рефералов, Mini App и значка.
Резервные копии до выкладки: `output/profile-scroll-server-backup-2026-10-24/`;
точные выложенные файлы: `output/profile-scroll-deploy-2026-10-24/`.

- JVM: реальный метод фона, единые координаты, отсутствие файла, ключи настроек;
  83 ссылки, включая новые адреса и отклонение некорректных/приватных адресов.
- JVM заголовков: обход источника, исключение самой панели, alpha, clipping,
  геометрия, поиск и выделение. 55 существующих контрактов настроек — PASS.
- HTTP API на отдельной временной MySQL БД: подписи, повтор nonce, фон GIF,
  владелец, бесплатный Full, возврат платной проверки, восстановление устройства.
  Тот же прогон выполнен с объединённым production bootstrap.
- PHP self-test с assert включён: оба значения флага — PASS. Имя `MySQL` не
  разрешается из Windows; проверка выполнена на локальном тестовом MySQL
  `127.0.0.1:3306`, root/root, в автоматически удаляемых БД.
- Production: публичный запрос badges — HTTP 200, license без сессии — HTTP 401;
  после FTP-выкладки байты файлов сверены.
- iOS: каталог 164 ключа / 3 языка и PostboxImportCheck — PASS. Добавлен XCTest
  сохранения/экспорта/сброса и ссылок новых опций.

Сборка и доставка APK записаны в `docs/build.md`. ADB не видит устройств.
Xcode, Apple SDK и XcodeBuildMCP недоступны: iOS не собран, XCTest не запускался.
Визуальные проверки тем, длинных заголовков, GIF, прокрутки и кадров анимаций
на Android/iOS не выполнены; внешний вид на устройстве пока не подтверждён.
