# Локальная активность из общих групп и видеообои — 24.10.2026

## Активность

Android и iOS сохраняют существующие прямые индикаторы Telegram и систему активности BYgram.
Новый источник работает рядом с ними только на устройстве. При открытии личного чата
клиент получает все страницы общих групп через Telegram `messages.getCommonChats`.
Для супергрупп используются штатные подписки на обновления: Android `startShortPoll`
с GUID экрана, iOS `AccountViewTracker.polledChannel` с отдельными disposables.
Это запросы к Telegram, без нового API или передачи наблюдений серверу BYgram.
История не помечается прочитанной.

Приоритет заголовка: действие непосредственно в личном чате → свежее действие этого
пользователя в общей группе → существующая активность BYgram → обычный статус Telegram.
Локальная строка содержит действие и название группы, например «выбирает стикер · Группа».
Учитываются темы форумов, текст, стикеры, запись/отправка видео, кружков, голоса,
фото, документов и игра; Android также сохраняет различие выбора контакта/геопозиции.
Чужие авторы и группы вне полученного списка не учитываются.

Android читает исходные `printingUsers` на `stageQueue` каждые 500 мс, выбирает
самое свежее подходящее действие и соблюдает штатный TTL: 5,9 с, для игры — 30 с.
iOS подписывается на `allPeerInputActivities`, включая штатные отмены и истечение TTL.
На iOS подключены оба рендера заголовка (`ChatTitleComponent`, `ChatTitleView`).
Наблюдения не пишутся на диск. Уход с экрана останавливает слушателей/опросы;
iOS различает аккаунты, собеседников и несколько экземпляров одного экрана.

Пока выполняется начальный поиск групп, новый механизм откладывает запрос старой
активности максимум на 10 с. При отсутствии локального действия старый механизм
продолжает работать. Поздний ответ API не перезаписывает свежую локальную строку.
Существующая публикация собственной активности, её согласие и настройки сохранены.

Ограничение Telegram: клиент показывает только реально полученные события.
Нельзя получить уже истёкшее печатание по запросу или гарантировать доставку каждого
действия. Число общих супергрупп влияет на сетевую нагрузку штатного опроса.
Новый источник не применяется к ботам, себе и секретным чатам.

## Видеообои

В меню чата доступны «Видеообои (локально)» и удаление видеообоев. На iOS пункт
открывает меню выбора/удаления, а обычные чаты получили дополнительную кнопку «…».
Android выбирает файл системным picker, iOS — видео из медиатеки.
Фон привязан к Telegram ID аккаунта и диалогу; темы одного форума используют один фон.
Доступен и для групп/каналов/секретных чатов/«Избранного», независимо от возможности
изменять общие серверные обои. Обычные обои остаются под видео и возвращаются после удаления.

Копирование и проверка файла идут вне UI-потока. Лимит — 100 МиБ;
Android также ограничен 3840 px по каждой стороне и проверяет декодирование первого кадра.
Неудачный импорт сохраняет прежний файл. Устаревший импорт после повторного выбора
или сброса не может вернуть удалённый фон. Файлы не отправляются в чат или на сервер.

Android использует существующий беззвучный `AnimatedFileDrawable` через `ImageReceiver`,
центрированное заполнение и освобождение декодера при паузе/закрытии чата.
iOS использует `AVQueuePlayer`/`AVPlayerLooper`, `resizeAspectFill`, выключенный звук
и остановку при уходе с экрана/в фон. Файл находится в Application Support и исключён
из резервного копирования iOS. Исходный URL picker не нужен после сохранения.

кадрам: выбор/сброс, повторный вход, фоновый режим, поворот, несколько чатов,
переходы к профилю и обычные/форумные группы. Видео должно плавно зацикливаться
без звука, лежать под сообщениями и останавливаться вне видимого чата.
