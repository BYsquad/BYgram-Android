# BYgram Android на базе Telegram 13.2.1

В локальную `main` вошли 25 коммитов `DrKLO/Telegram` после `3de37c8cf`
до `7be672ead` включительно. Обновлены gitlinks tgcalls, FFmpeg, libprisma и
libvpx. Пакет BYgram — `com.bygram.mobile`, версия универсальной сборки —
`13.2.1 (72919)`.

## Адаптация BYgram

- Вынесенные Telegram компоненты сообщений сохраняют значок и доступное
  описание удаления, настройку времени стикеров и значок редактирования.
  Предпросмотр результатов голосования учитывает локальную настройку и
  скрытие результатов до закрытия. Двойное нажатие на виджет обрабатывает
  сам виджет.
- Профиль использует новый источник стекла, включая пользовательский фон.
  Во время захвата стекла карточки пропускают его повторную отрисовку.
  Кнопка просмотров профиля следует за видимостью кнопок заголовка.
- Список чатов сохраняет стеклянный заголовок и настройку выравнивания.
  Главные настройки используют новый штатный заголовок Telegram.
  Переключатель активности Lite доступен в новом экране отладки.
- Новые виброотклики учитывают общий переключатель BYgram. Жест перехода
  видео в PiP использует сессию PiP Telegram 13.2.1.
- Правки локальных пакетов плагинов включены в Full Debug. Ключи настроек
  и идентификатор приложения сохранены для обновления поверх 13.1.1.

Для BYgram сохранён прежний путь входа. Firebase Phone Number Verification
остаётся выключенным до настройки и проверки сервиса для пакета BYgram.
Пункт сохранения выбранных файлов использует ограничения Telegram 13.2.1
для защищённых сообщений.

## Проверки

- Пройдены 20 наборов регрессий BYgram, JVM/Python-проверки SDK плагинов
  и проверка подписи пакета через Java, Python и PHP.
- На эмуляторе Android 37 (x86_64) APK установлен поверх 13.1.1 (72379).
  Открылись экран запуска, настройки Telegram и BYgram, Ghost, Spy и
  плагины. Переключатель полного фона профиля проверен и возвращён
  в исходное положение.
- На том же эмуляторе прошли диагностика Java/Python, конфликт двух
  хуков, выгрузка хуков и восстановление реестра. Первый запуск
  диагностики сразу после установки был прерван возвратом к главному
  окну. Повторный запуск после открытия приложения завершился успешно.
- Эмулятор был без активного аккаунта Telegram. Полный прогон сценариев
  в реальных чатах, звонках и профилях не выполнялся.
