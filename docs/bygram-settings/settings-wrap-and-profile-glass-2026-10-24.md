# Переносы настроек и стекло профиля — 24.10.2026

- Все `asCheck` и `asButton` в общем `SettingsList` BYgram получают перенос
  заголовков. Существующий `onBind` сохраняется. `TextCheckCell` использует
  штатный `setMultilineTextAndValue`, `TextCell` — многострочный `SimpleTextView`
  с пересчётом высоты. Остальные экраны Telegram сохраняют однострочный режим.
- При загруженном фоне и включённом «Растянуть фон на весь профиль» строки
  информации используют `iBlur3FactoryLiquidGlass`. Карточка музыки рисует стекло
  внутри своих границ вместо непрозрачной заливки. При отключённой опции или
  отсутствии изображения сохраняется обычное оформление.
- Источник стекла получает фон всего окна. Существующая стеклянная навигация
  SharedMediaLayout (публикации, архив, подарки) теперь размывает этот же фон.
  Захват содержимого списка в этом режиме исключён, чтобы стекло не захватывало
  само себя. Используется прежний ImageReceiver, включая обновления GIF.
  Ограничения Android и LiteMode для blur/Liquid Glass сохраняются.
- В Android en/ru/uk заменены тексты о Full, оплате, лицензии и подтверждении
  через бота (активность, статусы, просмотры и публикация фона). Идентификаторы
  ресурсов и параметры форматирования сохранены; механизмы доступа не менялись.
- В `BYxarek/BYgram-translations`, ветка `main`, обновлены три
  `bygram_strings.xml`, en/ru `bygram_desktop.json` и `ru/bot_messages.md`.
  Последний коммит: `d3caa94589e1e0cb6712bc9665f475b60f9dc6d2`.
  Пять файлов XML/JSON повторно прочитаны
  через GitHub API и совпадают с подготовленными данными. Ключи Desktop JSON
  содержат исходные английские фразы для совместимости; отображаемые значения
  больше не упоминают Full.

## Проверки

`Tools/check_bygram_settings_layout.py` исполняет реальный Java-метод измерения
TextCell с короткими/длинными заголовками, значением справа, RTL, выключенным
переносом и разделителем. Также проверяет подключение стекла, fallback и новые
формулировки. `check_bygram_profile_scroll.py` проверяет реальные координаты
фона и отсутствие изображения. Оба — PASS; 55 контрактов
`check_bygram_settings_fixes.py` — PASS.

ADB не видит устройств. Визуальная проверка стекла, GIF, светлой/тёмной темы и
масштаба шрифта на телефоне не выполнена. Сборка и доставка — в `docs/build.md`.
