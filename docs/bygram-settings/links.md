# Ссылки на настройки BYgram (Android)

Удержание пункта или категории открывает компактное меню с двумя действиями:
«Копировать ссылку» и «Поделиться ссылкой». Второе действие открывает выбор чатов
Telegram, а не системное меню Android. Удержание раздела BYgram в основных
настройках даёт ссылку на обзор.

Формат: `https://t.me/BYsettings?s=<раздел>[.<ID пункта>]`.
Идентификаторы не зависят от перевода, порядка строк и текущего значения.
Переход открывает раздел, прокручивает список и подсвечивает пункт; значения
настроек не меняются, сброс/очистка/публикация автоматически не выполняются.
Вложенные пункты Material 3 раскрываются при переходе, а параметры Ghost
доступны для просмотра и при выключенном главном переключателе.

| Раздел | Значение `s` |
| --- | --- |
| Обзор BYgram | `root` |
| Кастомизация | `customization` |
| Общие | `general` |
| Профиль | `profile` |
| Кастомные статусы набора (Full) | `typing` |
| Режим призрака | `ghost` |
| Режим шпиона | `spy` |
| Скрытые чаты | `hidden` |
| Защищённые чаты | `protected` |
| Просмотры профиля | `profile_views` |
| Передача активности (Full) | `activity` |
| Прочее | `other` |

Примеры: `https://t.me/BYsettings?s=ghost.2` — не читать сообщения;
`https://t.me/BYsettings?s=general.202` — переключатели Material 3;
`https://t.me/BYsettings?s=spy.6` — пункт очистки истории, без запуска очистки.
Полный список стабильных ID находится в `BygramSettingsLink`.
Новые пункты кастомизации: `profile.3` — скрыть свой номер, `profile.4` —
относительный онлайн, `general.8` — запрет свайпа из архива,
`general.9` — вибрация в приложении.
Для значка приложения и формы аватара ссылку можно получить удержанием заголовка.

Обработка HTTP-ссылок и `tg://resolve?domain=BYsettings&s=...` находится в
`LinkManager`, до обычного поиска username. Она требует авторизованного аккаунта.
PIN скрытых чатов и лицензия активности проверяются обычными точками входа.
В Lite ссылки на Full-разделы открывают обзор. Неизвестные адресаты и ID тоже
открывают обзор; перехода на Telegram-пользователя BYsettings нет.
Ссылки не содержат ID чатов, пользователей, паролей или настроенных разрешений;
списки конкретных пользователей не являются публичными адресатами.

23.10.2026: совместимый маршрут добавлен в исходники BYgram iOS через штатную
обработку settings URL. Долгое нажатие копирует/отправляет ссылку, переход
прокручивает и подсвечивает строку; iOS PIN и Full gates сохранены. Material 3
ведёт к пояснению о native components. Проверка iOS сборкой/на устройстве ещё
требуется. В обычных клиентах Telegram маршрут настроек BYgram отсутствует.

Пункт «Возможности BYgram (Telegram)» в основных настройках открывает фиксированный
`https://t.me/TelegramTips`: перевод интерфейса больше не подменяет адрес.

## Проверки

```powershell
$checkDir = Join-Path $env:TEMP 'bygram-settings-link-check'
New-Item -ItemType Directory -Force -Path $checkDir | Out-Null
javac -d $checkDir TMessagesProj/src/main/java/org/telegram/messenger/BygramSettingsLink.java Tools/BygramSettingsLinkCheck.java
java -cp $checkDir BygramSettingsLinkCheck
```

На авторизованном устройстве проверить: удержание категории/переключателя/
заголовка, копирование, отправку в чат и переход из сообщения, запуск по внешней
ссылке при закрытом приложении, подсветку нижних пунктов, выключенный Ghost,
свёрнутый MD3, PIN, лицензию, Lite/Full и неизвестное значение `s`.
