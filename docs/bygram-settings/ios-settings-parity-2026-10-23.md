# Сверка настроек iOS и Android — 23.10.2026

Сравнено актуальное рабочее дерево Android, включая новые настройки номера,
онлайна, архива, вибрации, заголовка и публичные ссылки BYsettings.
28 статических активных ключей: 22 прямых аналога iOS, 6 native adaptations.
Account-scoped сервисы и private chats сверены отдельно.

В iOS добавлены недостающие switches/consumers, выбор заголовка, архив через
штатную настройку Telegram, совместимые публичные ссылки с копированием,
выбором чатов, переходом и подсветкой. Upstream Telegram iOS перенесён в рабочее
дерево до `fb0e62ba8a147f0821da6aa63c09da7d79a10111` (13.1.1), локальные правки сохранены.

Полная матрица, платформенные различия, изменения API codec и проверки:
[отчёт в исходниках iOS](../../../BYgram-ios/docs/bygram-settings-parity-2026-10-23.md).
Swift typecheck, сборка, XCTest и runtime ещё не выполнены — Windows без Apple SDK.
Это состояние исходников, не подтверждение полного функционального совпадения на устройстве.
