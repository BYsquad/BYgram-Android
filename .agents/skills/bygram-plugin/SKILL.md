# Плагины BYgram · Общий

Для Codex, Gemini CLI и Cursor. Если пользователь явно указал этот скилл, используй остальную часть сообщения как описание задачи.

Открой [рабочий процесс BYgram](../../../docs/plugins/agent-workflow.md). Если относительная ссылка не разрешается, найди `docs/plugins/agent-workflow.md` от корня открытого репозитория BYgram Android. Руководство содержит ссылки на SDK, схему, примеры, команды сборки и тесты. Проверь документацию для целевой версии BYgram перед выбором API.

Доведи запрос до нужного результата: исходники и пакет для новой разработки или переноса, конкретные выводы для ревью, причина и проверенное исправление для отладки. При доступных инструментах выполни применимые проверки и укажи фактический статус локальных и Android-тестов. При отсутствии исходников SDK используй ссылки из [публичной документации BYgram](https://byxarek.site/TEST-PROJECT/BYgram/docs/) и запроси только данные, без которых нельзя подтвердить API или совместимость.
