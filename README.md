# BYgram для Android

BYgram — неофициальный клиент Telegram. Текущая база Android — Telegram 13.2.2.

Раздел **Настройки → Настройки BYgram** объединяет:

- **Приватность:** режим призрака для уведомлений о прочтении, онлайне и наборе; «Шпион» для локального сохранения удалённых сообщений и истории правок; скрытые и запароленные чаты.
- **Кастомизацию:** оформление списка чатов, папок и профиля, углы аватаров, отдельные компоненты Material 3, стеклянный стиль и кастомные статусы набора.
- **Сервисы BYgram:** управляемый доступ к активности, просмотры профиля и публичные фоны. Доступ и обмен данными зависят от функции, настроек и состояния аккаунта.
- **Плагины · БЕТА:** установка `.byplugin` из файла или каталога. Плагин запускается после отдельного согласия и получает доступ к процессу клиента; устанавливайте только доверенный код.

«Пламя» в личных чатах показывает серию дней, когда оба участника отправляли сообщения. [Правила серии](docs/bygram-settings/chat-flame.md).

[Скачать BYgram для Android](https://byxarek.site/TEST-PROJECT/BYgram/download.html). На сайте публикуется общее число устройств, запустивших версию BYgram с поддержкой счётчика.

BYgram использует пакет `com.bygram.mobile` и требует Android 7.0 или новее.
